# Deployment Guide

## CI/CD Pipeline (GitHub Actions)

File: `.github/workflows/flutter.yml`

Triggers on push/PR to `main`. Pipeline steps:

1. **Checkout** — `actions/checkout@v4`
2. **Setup Java 17** — `actions/setup-java@v4` with Temurin distribution
3. **Install Flutter** — `subosito/flutter-action@v2`, version `3.41.6` stable
4. **Create `.env`** — from GitHub Secrets (`SUPABASE_URL`, `SUPABASE_ANON_KEY`)
5. **`flutter pub get`**
6. **`flutter analyze --no-fatal-infos --no-fatal-warnings`**
7. **`flutter test --no-pub`**
8. **`flutter build apk --release`**
9. **Upload APK** as artifact (`hire-me-release-apk`, 7-day retention)
10. **Firebase App Distribution** — upload to `testers` group via `wzieba/Firebase-Distribution-Github-Action@v1`

### Required GitHub Secrets

| Secret | Purpose |
|--------|---------|
| `SUPABASE_URL` | Supabase project URL |
| `SUPABASE_ANON_KEY` | Supabase anonymous key |
| `FIREBASE_APP_ID` | Firebase Android app ID (from `google-services.json`) |
| `FIREBASE_SERVICE_ACCOUNT` | Full JSON content of a Firebase service account key |

## Build APK Locally

```bash
flutter build apk --release
```

Output: `build/app/outputs/flutter-apk/app-release.apk`

## Firebase Deployment

Run from the **project root** (not the `functions/` directory):

```bash
# Deploy Realtime Database rules
firebase deploy --only database

# Deploy Cloud Functions
firebase deploy --only functions

# Deploy Firestore indexes
firebase deploy --only firestore:indexes
```

### Deploy All at Once

```bash
firebase deploy --only database,functions,firestore:indexes
```

### Cloud Functions

Source: `functions/index.js` — Node.js 20 runtime.

6 v2 handlers:

| Handler | Type | Trigger |
|---------|------|---------|
| `onNewApplication` | Event-driven | Firestore `applications/{id}` onCreate |
| `onApplicationAccepted` | Event-driven | Firestore `applications/{id}` onUpdate |
| `onApplicationRejected` | Event-driven | Firestore `applications/{id}` onUpdate |
| `onNewChatMessage` | Event-driven | RTDB `chats/{chatId}/messages/{msgId}` onCreate |
| `rankCandidates` | Callable | HTTPS callable (Groq SDK) |
| `analyzeCv` | Callable | HTTPS callable (Groq SDK + Document AI OCR) |

Both callables use `GROQ_API_KEY` (set via `firebase functions:secrets:set GROQ_API_KEY`).

```bash
# Set secret for callable functions
firebase functions:secrets:set GROQ_API_KEY

# Deploy functions after setting secrets
firebase deploy --only functions
```

## Prerequisites

- Firebase CLI installed: `npm install -g firebase-tools`
- Logged in: `firebase login`
- FlutterFire CLI for initial project setup: `dart pub global activate flutterfire_cli`

## Environment Setup

The `.env` file in the project root must contain:

```env
SUPABASE_URL=your_supabase_project_url
SUPABASE_ANON_KEY=your_supabase_anon_key
```

`firebase_options.dart` is generated by `flutterfire configure` and must **not** be edited manually.
